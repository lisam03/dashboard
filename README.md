# Прототип інформаційно-аналітичної панелі

Прототип для магістерської роботи: **«Математичні моделі та архітектура інформаційно-аналітичної панелі для візуалізації результатів оброблення даних у зручній для оператора формі»**.

## Структура

```text
app.py
requirements.txt
README.md
data/
  __init__.py
  generator.py
core/
  __init__.py
  processing.py
  anomaly.py
  ahp.py
  klm.py
ui/
  __init__.py
  baseline.py
  optimized.py
  experiment.py
```

## Локальний запуск

Python 3.11:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Режими задаються URL-параметром:

- `?mode=baseline`
- `?mode=optimized`
- службова аналітика: `?mode=optimized&admin=1`

Учасник не має елемента інтерфейсу для перемикання режиму.

## Потік даних

Дані генеруються детерміновано з `seed=42`. У прототипі `st.autorefresh` запускає повторний рендер приблизно кожні 2,5 с; це імітує надходження нового кадру та дозволяє вимірювати затримку оновлення.

## Google Form / SUS

У `ui/experiment.py` замініть `SUS_FORM_URL` на URL власної анкети SUS.

Код результату має формат:

```text
режим;псевдонім;t1;t2;t3;t4;помилки
```

## Streamlit Community Cloud

1. Створіть GitHub-репозиторій і завантажте всі файли.
2. У Streamlit Community Cloud створіть новий застосунок.
3. Вкажіть репозиторій, гілку та файл `app.py`.
4. Дочекайтеся встановлення `requirements.txt`.
5. Для експерименту використовуйте окремі URL режимів, наприклад `...?mode=baseline` і `...?mode=optimized`.
6. URL `?admin=1` не є механізмом автентифікації. Для реального захисту службової аналітики потрібна автентифікація/секрети або окремий приватний застосунок.

## Примітка щодо експерименту

CSV з Google Sheets можна завантажити у службовій вкладці. Якщо присутні `SUS1` ... `SUS10`, розрахунок SUS виконується автоматично за стандартною формулою: непарні твердження мають перетворення `x-1`, парні — `5-x`, після чого сума множиться на 2,5.

PNG-графіки для диплома можна експортувати з відображених Plotly-графіків або додати окремий модуль експорту; базовий прототип навмисно не записує файли на Streamlit Cloud.
